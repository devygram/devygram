## 🛠️ Getting Started

```bash
# Clone the repository
git clone https://github.com/devygram/devygram.git
cd devygram

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
